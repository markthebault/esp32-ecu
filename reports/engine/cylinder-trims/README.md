# Cylinder trim evidence

Four physical-cylinder 6×6 fuel maps and signed spark offsets now span control, schema 3 storage, browser tuning, own 003 MSQ and channel diagnostics. [Configuration and limits](../../../docs/engine-cylinder-trims.md) explain the existing J9/J10 channel mapping and inhibited physical policy.

- `comparison.json`: nine independent unequal-cylinder plant cases, including disabled, neutral, inverse-flow, swapped C2/C3 and separately labelled Speeduino total-PW calibration. The final publication run records each live reference executable digest before simulation and checks it against the build manifest.
- `transients.json`: nine further runs covering 125/250 µs convergence, throttle, cam loss, batch regression and native32 sensitivity; 13 replay/equality/convergence checks.
- `recorded-execution.tar.xz`: final eighteen runs and execution-source hashes. Baseline cases contain raw combustion records and edges; transient cases contain edges, shaft traces and spark records. `reviewed-execution.tar.xz` preserves the original eighteen runs assessed by the independent reviewer, before stronger assertions and fingerprint recording. `publication-equivalence.json` checks that the publication repeat preserves the reviewed control/plant timelines.
- `independent-plant-review.json` and `independent-probes.tar.xz`: independent pulse/physical-angle/fuel/energy replay, six additional fine-step/fuel-only/spark-only runs and source probes. Aggregate speed/fuel/work convergence does not establish convergence of the very small residual cylinder CV.
- `independent-core-*`, `independent-reference-*`, `independent-timing-review.json`: design, schema/migration, allocation ownership, command acceptance, actual production reference mapping and the six-microsecond charged-coil/tooth fault. The bounded guard preserves its committed discharge without increasing dwell limits.
- `independent-target-review.json`, the three ISR audits and `firmware-build.log`: final source/ELF binding, static IRAM/DRAM placement, selected/generic engine-output inhibition and stack/layout checks. Static RAM is 145,156 B selected, 143,904 B generic and 118,904 B dummy. Runtime stack/heap/IRQ timing remains unmeasured.
- `python-tests.log`: 108 tests. `native-tests.log`: ten sanitizer binaries including 117 control scenarios and allocation failures. `radio-tests.log`: the additional ESP-NOW sanitizer binary plus existing Python suites. Five Chrome reports total 45 checks.
- `tunerstudio-check.json`, screenshots and the [application-authored 003 MSQ](../../../tuning/examples/tunerstudio-cylinder-roundtrip.msq): actual offline edit/save/native import. Live own-controller acceptance and physical tuning transport remain unresolved.
- `megalogviewer-check.json`, `browser-cylinder.msl` and screenshot: actual unchanged MegaLogViewer HD Lite opens 79 fields and plots distinct cylinder proposals. The older missing-lambda derived-AFR caveat still applies.
- `cylinder-comparison.png`, SVG and standalone HTML: scientific figures generated by `tools/plot_cylinder_comparison.py`.
- `validation-summary.json` and `artifact-hashes.json`: commands, source/runtime/build fingerprints and artifact hashes. Linked reference executables and commercial applications are not distributed here.

The external MVEM air path is hash-verified. Fuel transport, combustion, injector, coil and free-shaft assumptions are local, empirical and uncalibrated. Plant flow/spark constants are independent of either controller. The separately calibrated reference uses known simulated flow/deadtime and one idle operating point. Rich absolute lambda remains, so the result demonstrates balancing rather than optimal tuning or numerical ranking of ECUs.

Native execution has zero CPU/IRQ cost. The 16-bit reference is a Mega-like timer HAL, not AVR/peripheral emulation. No target was flashed. Physical output timing, electrical loads, engine/vehicle behavior, RF/module fit, EMI/surge, thermal, splash and printed-fit qualification remain undone. Historical CAD/manufacturing records are unchanged.
