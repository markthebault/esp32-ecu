# Independent load-model architecture assessment

Reviewed baseline: `1d6a9acb34838ea175f2dfa7ccd9786e96d2d11b`.
Reference: Speeduino `9ff5aae44de51fdc00d3fb1c7c2bfc1f0d0b3e20`.
Date: 2026-11-04. Reviewer: independent child agent, read-only production access.

This is an architecture assessment and controlled native-function probe. It does not approve the implementation being written concurrently, establish engine feature parity, or validate physical outputs, an actual engine, boost operation, or vehicle conditions. All created files are under this cache directory. Existing review evidence is retained.

## Conclusion

Implement table coordinates, pressure normalization, AFR incorporation, sensor requirements, and axis metadata as separate explicit concepts. MAP/TPS/IMAP-EMAP alone is a table selector. TPS indexing with physical MAP still multiplied into charge is a hybrid TPS-indexed speed-density model. Pure Alpha-N requires no hidden physical-MAP factor. An IMAP/EMAP coordinate is a dimensionless ratio percent and can exceed100% without manifold boost.

Root's proposed first increment is coherent: independent primary fuel/spark sources; lambda and trim sources that can follow primary fuel or be explicitly independent; Off/MAP÷100/MAP÷baro pressure modes; a deliberate J16 role; explicit axis-basis metadata; exact historical MAP defaults. Root subsequently added mutually exclusive AFR multiplier choices to the planned increment, with a declared running delay and neutral readiness/loss policy. Secondary fuel/spark combinations and switches, plus the separate barometric fuel-correction curve, remain explicit open gaps. This increment does not by itself close full load-feature parity.

## Existing project's contract

Frozen `engine.hpp:179-236` indexes VE, spark, lambda and enabled cylinder trims with physical MAP. Its charge expression is absolute MAP×cylinder volume×VE/(R×absolute IAT). Target lambda always divides fuel, independently of EGO. This matches target incorporation, not Speeduino's all-AFR-flags-off behavior. Reference adder is a full-cycle fuel dose at100kPa/25°C/100%VE/λ1 and is independent of current MAP/VE/WUE/EGO; complete dose is trimmed, split by actual openings, then deadtime is added per opening.

Legacy tune validation limits VE20..120%, MAP axes5..110kPa and measured MAP10..110kPa. Spark is−5..40°, target lambda0.75..1.2. Four-cylinder NA constraints, duty/pulse/timing limits, hard cuts and physical output inhibition are separate requirements and must remain intact.

Binding currently requires confirmed non-voltage MAP/TPS/CLT/IAT calibration. All acquisition values share the current ADC sample timestamp. ADC channels0..3 are those four inputs,4 is wideband,5 is POSTCAT/J16,6 battery,7 sensor rail. `config::convert` qualifies units and conversion; do not claim that a configuration field named filter_ms proves an actual matched pressure filter in this path. CAN currently has no implemented pressure-source decoder/freshness contract.

## Recommended explicit contract

1. **Sources and metadata.** Use closed enums for MAP kPa, TPS percent and100×IMAP/EMAP percent. Primary fuel and spark select independently. Lambda and trims default to follow primary fuel, with optional independently declared sources as an extension beyond this pinned reference. Resolve follow-primary to the original primary coordinate even when a secondary fuel table is active. Keep physical MAP/TPS separate from each table's derived coordinate. Unknown enum/basis, nonfinite value or source/basis mismatch rejects the tune.

2. **Pressure and charge.** For new modes, define normalized reference charge using fixed100kPa and actual IAT, multiply by fuel coefficient and selected pressure factor1, MAP/100, or MAP/baro. Pure Alpha-N is TPS indexing plus pressure factor1. TPS with MAP/100 remains hybrid. IMAP/EMAP does not replace the pressure factor unless explicitly selected. Do not make reference pressure equal baro and silently cancel MAP/baro. Preserve the original arithmetic expression on the exact legacy-default path so migration is bit-stable. Report the charge basis; Alpha-N normalized charge is a fuel-model proxy, not independently measured trapped air.

3. **AFR incorporation.** Expose mutually exclusive Off, TargetIncorporation=1/target_lambda and MeasuredToTarget=measured_lambda/target_lambda, or list absent modes as open gaps. Define wideband warmup/freshness/invalid behavior explicitly. If measured-ratio and EGO PI may operate together, show both factors and deliberate compounding. Otherwise reject the combination with a meaningful error. A target table may still serve EGO when target incorporation is off; requirements must follow actual consumers. Define measured-mode delay against a genuine start epoch, not each rev-cut or transient-fault recovery. Record requested mode, applied factor and neutral reason separately. Zero ordinary fuel freezes EGO even if an absolute transient adder is present. Default/migrated behavior remains current TargetIncorporation. Retuning is required when these factors change.

4. **Zero and large coefficients.** If new schema permits0 or coefficients above120, retain old schema/MSQ rejection for historical invalid tunes before upgrading. Final zero fuel must suppress deadtime-only pulses. Positive reference adder with zero ordinary base may produce finite absolute fuel, but effective ratio is undefined: no division by zero and no fabricated finite ratio. Record absolute added fuel and an unavailable-ratio flag/null. DFCO, explicit transient cut and all fault cuts dominate the adder. Judge channel capacity after actual trim and openings. Secondary coefficients may exceed old120 or clamp; expose final clamping rather than silently assuming the primary limit.

5. **Baro.** Choose fixed manually calibrated absolute kPa or a dedicated qualified live input. Root's choice to omit automatic pre-crank MAP capture is defensible and safer than treating unsynced RPM0 as stopped. Fixed is a declared manual value, not an acquisition sample; do not label it live or infer sample freshness. Live loss has no silent fixed100kPa fallback. Baro curve, if added, is an additional correction with its own enable and source dependency. Declare software pressure bounds and the supported altitude envelope, rather than copying an unrelated table-axis bound.

6. **J16 routing.** Default remains POSTCAT monitor. Optional EMAP or external baro must be an explicit exclusive role requiring confirmed, non-voltage absolute-kPa calibration, current acquisition quality and freshness. Live EMAP plus live external baro cannot both consume this channel. A fixed baro plus EMAP is possible. Supporting simultaneous live EMAP, baro and wideband requires another protected input or a real external/CAN acquisition implementation. EMAP needs a suitable conditioned pressure transducer and installation; the raw exhaust path/sensor heater cannot be connected to the protected analog input as if it were a voltage signal.

7. **EMAP and ratios.** Check finite, calibrated, fresh, strictly positive bounded EMAP before division. Define its acquisition bounds independently of MAP's NA110kPa cap; backpressure can exceed110kPa while the manifold remains NA. Define a separate ratio-axis domain capable of values above100%. Example100/80 yields125%. Do not clamp it to100 or reuse kPa labels. Axis endpoint clamping may remain normal lookup behavior, but report clamped coordinates; invalid denominator must inhibit rather than silently select an endpoint/fallback source. Exact numeric EMAP and ratio domains must be tied to the explicitly supported sensor/calibration domain and tested, not guessed from the old MAP axis.

8. **Sensor requirements.** Derive a requirement mask from every enabled consumer. MAP is required for MAP or ratio coordinates, MAP pressure factor, active MAP AE, and any configured secondary MAP condition/source once those features exist. EMAP is required for ratio. Live baro is required for MAP/baro and an enabled baro curve. Lambda is required for measured-ratio and qualified EGO operation according to their declared warmup/fault policy. Keep TPS/CLT/IAT, battery/rail, ADC health/overflow, trigger/synchronization, timing and thermal checks. Configuration metadata and runtime qualification are separate: an unused input is not automatically valid. Conversely disabled tables do not create a runtime dependency merely because retained cells exist. A future-enable transition must validate all its dependencies atomically.

9. **MAP-less behavior.** It is acceptable only when every active consumer is independent of MAP. Missing/unconfirmed MAP remains unknown, input-valid clears, and MAPdot stays unknown. Do not fabricate100kPa for inputs, logs or ESP-NOW. A confirmed finite over110kPa reading remains an independent NA fault even if unused for fueling. Show when the pressure guard is unavailable. This software mode cannot establish that the actual engine is NA or authorize boost. TPS-rate enrichment needs an explicit optional-MAP path; its default standalone validity contract can remain strict. Optional unknown MAP must not inhibit TPS enrichment or contaminate history with fabricated values.

10. **Clock and revisions.** Require the same coherent acquisition and sample age contract for the role channel as other analog inputs. Require no zero/future/reversed/unbounded-hold values. Tune or calibration revision changes must prevent mixed old basis/new numbers and clear applicable EGO/AE histories. Enabling a previously unused pressure must not reuse an old valid flag. Evaluate calibration unit/role/confirmation every binding, not only when the tune is saved. No stateful pressure fallback on fault or source switch.

## Secondary-table scope and ordering

Full reference load-feature coverage requires secondary fuel and spark tables with their own sources plus Off/Multiply/Add/Conditional/InputSwitch. Continuous blending, if desired, is an additional explicit feature. Blend table outputs or fuel doses using a declared coefficient; never average kPa and TPS-percent coordinates.

For multiplication a neutral fuel table is100%; for addition it is0. Spark multiplication cells are percent and additive/switch cells are degrees, so a mode change also requires metadata/reinitialization rather than reinterpreting old angle numbers. Conditional thresholds need source-specific units, edge semantics and any intentional hysteresis. RPM/MAP/TPS are existing quantities, while ethanol/input-switch choices require real acquisition/routing support. Do not display an unsupported physical switch as functional.

Preserve primary load for follow-primary lambda/trims through all fuel secondary modes. Apply mandatory spark cuts/fixed/cranking behavior and carrier timing bounds after explicit secondary composition, while preserving soft-limit retard. Document where project order differs from pinned production corrections. Keep effective-fuel trim before deadtime as the project's declared behavior; the expected reference difference is approximately `(trim_factor−1)×deadtime`, plus integer quantization. A successful untrimmed PW match does not establish matching trimmed dose.

## Configuration, UI, tuning and observability acceptance

Store axis_kind/unit metadata for each primary, lambda and trim table, plus secondary maps when added. A fuel-source change affects follow-primary children as well. Reject mismatches even if old numeric MAP bins happen to fit0..100 and could otherwise pass a TPS validator. There is no engine-independent kPa-to-TPS axis conversion.

Source/pressure/AFR changes should make a reviewable draft that explicitly names affected axes, retained cells and retuning requirement. Offer deliberate source-specific axis initialization; preserve old cells unless the user requests reset. Changing axes while retaining cells is a user-chosen retuning starting point, not a calibrated conversion. Disabled retained maps may keep their own declared basis, but cannot be enabled with a mismatch. All changed tables/selectors/bases burn as one validated tune with CAS, persistence failure retention and no partial activation.

JSON schema7 and own008 should append typed selectors/metadata without altering the frozen own001..007 meanings. Legacy JSON/MSQ must first pass its own historical bounds and shape, then receive exact MAP/pressure/target defaults. No old document may silently activate a new pressure role. Keep original stored bytes until explicit save. New MSQ/INI exports must carry physical units and matching basis; new imports reject wrong-source/unknown/duplicate/truncated metadata and incompatible signatures. Historical INIs remain records. Actual TunerStudio table axes, page numbers, source labels, offline edit/export/reimport, and live readback need GUI acceptance, not just generated-file parsing.

At minimum observe source enums; raw MAP/TPS/EMAP/baro with qualification and source age; required-input mask; fuel/spark/lambda/trim derived coordinates and basis; pressure factor; AFR mode/factor/readiness; coefficient before/after secondary; separate baro correction; ordinary and added fuel; zero-cut/clamp reasons; optional-pressure-guard availability; tune and sensor revision and data source. Fresh, unused, unqualified and unavailable are distinct. Preserve old log prefixes and precision with explicit new availability/basis fields. Existing8-bit input_valid already covers8 inputs; do not alias an old bit for EMAP/baro. JSON/null, MSL blank/NaN and tuning sentinel behavior must agree. ESP-NOW consumers need versioned availability rather than assuming added fields are always real target measurements.

1. New default/migrated tunes reproduce all324 frozen rows and all legacy-valid/invalid outcomes. 3. Run every pressure dependency with missing calibration, wrong unit, voltage mode, unconfirmed value, NaN/Inf/zero, under/over-range, stale/future timestamp and sensor-revision change. Verify no invalid divide or fallback. Test J16 role conflicts and no hidden bypass of ADC/rail/NA checks. Optional unknown MAP must be visibly unknown while valid TPS-rate enrichment continues.
4. Execute actual pinned reference getLoad/target/PW functions with read-back configurations, then native loop/ADC/trigger/edge comparison for selected modes. Account for raw10-bit ADC, TPS0.5%, MAP/EMAP integer kPa, load-axis and AFR0.1 quantization, Q7 multipliers, integer percentage rounding, reqFuel0.1ms and per-opening deadtime. Set explicit MAP sampling/filtering and EMAP enable/calibration. Reference rates are MAP1kHz, TPS30Hz, O230Hz, CLT/IAT/battery4Hz and baro1Hz (`sensors.h:52-79`); our raw ADC path is5ms. Capture held sensor values and output transitions, not ideal commanded floats. A controlled-status PW probe is not this loop comparison.
5. Keep native timer16/32-bit, wrap, loop cadence and zero execution cost assumptions explicit. No timer configuration proves physical timing. When using secondary spark switch, use production UNIT_TEST=false so corrections remain in the path.
6. Feed both ECUs' executed virtual injector/spark edges into the same frozen independent plant with separate instances. Compare pulse-derived dose, channel/stroke phase, actual lambda after transport delay, stable/stall response, hard-cut timing and conservation residuals; predeclare tolerances from reference quantization and integration convergence. Do not tune different physics for each controller or optimize until ours wins.

Current100kPa runs cannot validate altitude compensation or IMAP/EMAP behavior. Include frozen-axis negative controls: wrong MAP/100 vsOff, wrong source/units, swapped EMAP/baro, incorrect calibration, disabled correction at changed ambient, stale denominator and zero/base-adder cases should be detected by tests.
8. Alpha-N requires its own RPM/TPS calibration derived from an independent plant or held-out reference data. Reusing the old MAP VE cells is not evidence that Alpha-N can run correctly. Freeze calibration/train scenarios separately from held-out throttle ramps, IAT/ambient/load changes and sensor failures. Keep the reduced-order plant explicitly unvalidated; no result establishes a perfectly running real engine, EMI/surge, thermal, printed-fit or car qualification.
