# Whole-tune development transport increment

This increment adds the shared own004 C++ tuning Session/Stream, a dedicated inhibited ESP32 native USB task, a complete-page INI/MSQ workflow and authenticated UI diagnostics. It does not establish full Speeduino parity, online TunerStudio support or physical USB/engine qualification.

- [122 Python tests](python-tests.log), [native sanitizer tests](native-tests.log), [final optional-origin tests](optional-origin-unit-tests.log) and 46 Chrome checks pass. Chrome reports cover [tuning](tuning-ui-tests.json), [engine](engine-ui-tests.json), [cylinders](cylinder-ui-tests.json), [sequential control](sequential-ui-tests.json) and [observability](observability-ui-tests.json).
- [Three firmware builds](firmware-builds.log) pass. Selected N16R8 uses 145,252 bytes static RAM and 1,311,497 bytes factory-app flash. These numbers exclude dynamic stack/heap requirements. [Selected](selected-isr-audit.json), [generic](generic-isr-audit.json) and [dummy-load](dummy-isr-audit.json) engine ISR placement checks pass.
- [Separate USB build audit](usb-selected-audit.json) verifies the local pinned driver, retained global SDK, UART0-only console and flash-resident USB ISR with flags 0. The engine ISR audit does not cover USB cache safety. Actual bus traffic, boot/panic output, sustained load, driver RX loss, minimum heap, stack high-water and physical timing remain unmeasured.
- [Nine plant runs](comparison.json) exercise four project tunes committed through own004 before starting the target-core native simulation, and five actual pinned Speeduino profiles. Neutral, corrected, wrong-cylinder and reference total-PW/deadtime policies remain explicit. The independent MVEM air path plus local empirical combustion/free-shaft plant is uncalibrated. This does not model hot-running USB commits. Complete raw traces are in [plant-traces.tar.xz](plant-traces.tar.xz).
- [Independent core/target review](independent-core-review.json) covers 270 maximum-frame splits, 267 corruptions, stable-origin/CAS behavior and all 2412 cJSON failure positions in the native bridge and actual target-service fake harness. [Independent storage review](independent-storage-review.json) adds 7000 allocation-budget outcomes, NVS failures and browser revision races. [Supplemental origin review](independent-origin-review.json) checks the actual application file, invalid supplied origins/bases, all 76 other required fields and stale-editor CAS. [Final fallback/image review](independent-fallback-review.json) confirms failed host observations keep inhibition visible, clear stale fields and make zero commits, with refreshed audits matching all three final images. Reproducible probe sources/snapshots/logs are in [independent-probes.tar.xz](independent-probes.tar.xz). These hooks do not cover every SDK allocator or physical flash behavior.

The tested unmodified TunerStudio MS Lite 3.3.01 parses the own004 INI and saves an offline tune with C2 spark −2.5° and C2 fuel 120%. It omits read-only origin metadata; the importers handle that explicitly. [Application result](application-result.json), [wire capture](application-wire.log), [debug log](application-debug.log), [offline screenshot](application-offline.png) and [saved fixture](../../../tuning/examples/tunerstudio-development-roundtrip.msq) retain the evidence.

Online discovery produced 92 unsupported-own-identity warnings, 368 valid framed requests/replies and zero calibration reads/writes/burns. A separate own003 [F002 comparison](application-f002-comparison.json) shows that correcting the serial revision did not remove the application gate. Earlier units warnings in the application log belong to intermediate exports; the final-units load has no new unit warnings and the subsequent application-saved file is validated. No app patch, foreign signature, license bypass or vendor message was used. [Vendor request draft](../../../tuning/vendor-integration-request.md) remains local and unsent.

[Source/build binding](verification.json) and [artifact hashes](artifact-hashes.json) distinguish the final increment from earlier reviewed snapshots. The final core matches reviewed source.
