# Independent IAC-DRAFT2 circuit and copper review

Initial review 2026-11-04 at ECU commit `497aabb4a0ea686b240182e42b4c64aefa280c32`. Scope: the new isolated accessory only. A5 carrier routing and physical acceptance are separate. This reviewer changed no production files, started no services, used no hardware writes, contacted no vendors and made no purchases.

**The first routed snapshot needs layout correction before proceeding toward a powered fixture.** Its pin map, return isolation and intended power copper pass the checks below. ## Concrete findings, in priority order

1. **High, gate-driver current return is long and shares coil-return copper.** In initial PCB SHA256 `78edb587f537f692df9ed0a06e4511a5b40fcc17bcde72a1a8da44223bb975fe`, U1 pin3 to Q1 source pin3 takes **51.560 mm** of trace centerline. It joins the 2 A return at `(95.08,53.8984)` rather than the source `(95.08,39)`, sharing **14.8984 mm** of the main source-to-J2 trace. Gate-drive signal copper is another 14.571 mm, plus the R13 body/lead path. Thus the gate charge/discharge loop includes the shared coil return and a large detour. Add and retain a short source-to-driver return meeting at the Q1 source pad; route outgoing drive and return together where possible. This is a concrete topology/layout correction; trace lengths alone are not a computed transient voltage. [TI UCC27524](https://www.ti.com/lit/ds/symlink/ucc27524.pdf), sections9-10.

2. **High, driver bypass is not local and its nearby larger capacitor is absent.** C4-to-U1 pin6/pin3 copper totals **23.973 mm**. C4 ground is `(83.5,44)`, U1 ground `(68,43.08)`; its return detours through the grounded ENB pin8 area. The only 22 uF capacitor C7 is **61.900 mm** away around the combined rail/return paths. The TI application guidance calls for a nearby 100 nF capacitor plus a nearby larger low-ESR capacitor. Place both across the driver power/ground with short stubs, while preserving the user's THT constraint; validate actual lead/trace inductance and ringing on the fixture. No arbitrary PDIP drive guarantee is supplied by the current D/DGN/DSD electrical table. [TI UCC27524](https://www.ti.com/lit/ds/symlink/ucc27524.pdf), sections8.2/9/10.

3. **Medium, the other decouplers also have avoidable return detours.** Combined supply/return copper centerlines are U2/C1 **22.698 mm**, U3/C2 **26.963 mm**, U4/C3 **41.561 mm**, U5/C5 **16.228 mm**. For the optos, capacitors are above the package and their ground pads do not return directly to pin5. U4's power pins are diagonally opposed in PDIP14, but the existing route adds an avoidable detour through the signal-side ground network. Place the opto decouplers beside their detector pins and shorten these local return loops. Native connectivity and the opto's switching-table load are separate issues: neither the 1 k pullup nor an unmeasured board load inherits the 350 ohm/15 pF timing result. [Vishay 6N137](https://www.vishay.com/docs/84732/6n137_vo2601_vo2611.pdf), pages3-5; [TI HCT02](https://www.ti.com/lit/ds/symlink/sn74hct02.pdf), pin diagram and application guidance.

4. **Low, new-project provenance notice has a broken relative link.** `hardware/idle-isolated/lib/NOTICE.md` points to `../terminal-source.json`, which is absent from this new project. Its correct pinned primary source record is currently `hardware/idle-accessory/terminal-source.json`; the copied footprint itself verifies. Fix the notice link or carry the actual provenance record into the new project. The separate new 1N4007 footprint is properly pinned in `new-footprints.json`.

Pin diagrams in downloaded PDFs were rendered and inspected. The onsemi/JST direct downloads were blocked; primary web records were opened, without a claimed byte hash.

The actual board outline is **90 x 60 mm**, two copper layers,1.6mm substrate. Every electrical pad is plated through-hole, drills0.8-1.7mm, and there are no vias or SMD pads. All ICs use direct-solder DIP footprints, with no socket part. This passes the stated electrical-layout form and <=120mm size constraints, without establishing an enclosure/lead-bend/heatsink/connector fit.

The copper-empty rule area is x35.3..40.3 across y10..70 on both copper layers; tracks, vias, pours and pads are forbidden. Independent bounds including NC opto pads give carrier copper rightmost x35.2 and actuator copper leftmost x40.42: **at least5.22mm horizontal copper separation**. No power zone crosses the barrier; no mounting copper connects the domains. A conservative graph joins every ordinary component's non-NC pins, splitting only each opto's LED and detector halves. There is no ACT_GND-to-any-J1 conductive path. Deliberately bridging ACT_GND/CARRIER_GND restores a path as the negative control. This is intact-barrier DC topology, not certification or a semiconductor fault model.

All **15 intended locked2mm power segments** survive the autorouter exactly: J2 positive-to-J3 positive, J3-to-flyback cathode, flyback anode/J3 low-side-to-Q1 drain, and Q1 source-to-J2 return. The source-to-J2 return is18mm, with no via or thin-control neck. Flyback-to-J3 branch lengths are23.314mm and13.814mm; the external harness/coil loop is additional. These checks do not establish copper temperature, diode temperature or permitted harness length.

The eight-row logic/PG truth table is retained in the probe. With valid local power, both LEDs must conduct for drive; either LED dark, a low NOR output, or low ENA blocks drive. The supervisor pulldown and independent enable are present. The logic truth table does not prove arbitrary brownout timing or instantaneous mechanical closure.

## Release holds that remain regardless of a routing correction

- Freeze the guaranteed data for the actual procured UCC27524P/P.B; current electrical/pin tables explicitly cover D/DGN/DSD while the orderable addendum offers P. [TI product record](https://www.ti.com/product/UCC27524).
- Loaded GPIO3 voltage, RUN source loading, 2N3904 saturation/storage versus temperature, opto LED current and actual pullup/capacitive timing require measurement. The 357ohm current envelope depends on rail/VF/VCE assumptions; the BJT's limits are given at25C and specific current pairs. [onsemi](https://www.onsemi.com/download/data-sheet/pdf/2n3904-d.pdf), [Vishay](https://www.vishay.com/docs/84732/6n137_vo2601_vo2611.pdf).
- MCP100 assertion delay and hysteresis lack maximum specifications; do not claim an unconditional fast-brownout fail-low result. Static trip headroom remains narrow. Bench startup, interruption and brownout with the actual assembled rail and driver. [Microchip](https://ww1.microchip.com/downloads/en/DeviceDoc/11187f.pdf).
- An independent16-corner recomputation of the120/374ohm divider gives4.9673-5.3459V, assuming actual9-16V at the regulator input and the selected1% parts. This is neither overshoot nor thermal acceptance. Add exact THT capacitor/resistor selections and measure rail/load transients, hot regulator/diode/FET temperature, and capacitor ripple/voltage margin. [TI LM317A](https://www.ti.com/lit/ds/symlink/lm317a.pdf).
- Accepted software PWM can contain a1us pulse. Establish a measured physical minimum reliable pulse; a40us test at250Hz/1% cannot close that gap. Preserve the disabled physical policy while unresolved.
- Specify and verify an independent actuator-branch disconnect. A grounded drain tab or drain-source short can energize an otherwise normal-current coil continuously and need not clear a fuse. Both TO220 tabs are live; define insulating spacers/heatsinks/case fasteners. [Infineon](https://www.infineon.com/assets/row/public/documents/24/49/infineon-irlz44n-datasheet-en.pdf), [TI LM317A](https://www.ti.com/lit/ds/symlink/lm317a.pdf).
- A5 module fit, permanent GPIO3 strap bias and actual module/eFuse/JTAG routing remain outside this accessory review. Firmware snapshot keeps `ECU_IDLE_DUMMY_LOADS` default0 and rejects selected-N16R8 physical enable. No flash/eFuse operation is authorized or needed for this review.

Use a current-limited resistor fixture first, observing rails/PG/gate/drain/load through startup, EN/reset/download, watchdog/interlock/stalled producer, input opens and both power-return opens. Freeze the externally protected switched/fused branch and the actual <=2A NC valve R/L before load testing. No engine, certified isolation or vehicle qualification follows from these desktop checks.
