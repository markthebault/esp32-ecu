Footprints are copied from the project’s existing KiCad library copies, except DIP18 from the pinned official KiCad GitHub archive. Source/copy hashes and the DIP18 commit/URL are in ../footprint-provenance.json. See https://www.kicad.org/libraries/license/ for the KiCad library license and exception. Unsupported KiCad10 false-jumper/construction metadata is omitted for Linux KiCad9; pad/copper/courtyard geometry is retained. Referenced3D models are not verified assemblies. Symbols are generated by scripts/build_hardware.py and exact manufacturer pin maps remain a physical procurement/assembly check. No original carrier/library source is modified.
