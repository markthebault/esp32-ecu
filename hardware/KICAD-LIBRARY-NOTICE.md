# KiCad library attribution

The project-local footprint collections under `hardware/lib/ecu.pretty` and the revision-specific `lib/ecu.pretty` directories include data copied or adapted from the KiCad footprint libraries. Copyright belongs to the KiCad library contributors. Component names and upstream descriptions remain in the footprint files. Project-specific footprints and assembly envelopes are also present.

Upstream library material is provided under [Creative Commons Attribution-ShareAlike 4.0 International](https://creativecommons.org/licenses/by-sa/4.0/), with the [KiCad electronic-design exception](https://www.kicad.org/libraries/license/). This notice does not assign a license to the project's original firmware, documentation or hardware design.

Upstream source: [KiCad footprint libraries](https://gitlab.com/kicad/libraries/kicad-footprints).

Modifications include project-local identifiers, module/header footprints, direct-solder DIP variants and compact assembly graphics. The checked native PCB, assembly documentation and BOM identify the parts used by each revision. Stock 3D model references require the user's installed KiCad 3D libraries; the local simplified module/connector envelopes are described in their own README files.
